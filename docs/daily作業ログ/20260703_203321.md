- 既存の `image_or_graph` / `version_diff` / `password_protected` / `multi_hop` / `text_only` の動作は維持。

### Task 2: 構造化artifactsロード層

- `StructuredArtifactStore` を追加。
- 読み込み対象:
  - `highlight_cells.jsonl`
  - `schedule_tasks.jsonl`
  - `office_marks.jsonl`
  - `train_xlsx_highlight_blocks.jsonl`
  - `train_xlsx_sheets.jsonl`

- 案件名ごとに絞り込むメソッドを提供。
- 実データで macOS由来のNFD/NFC表記ゆれがあったため、案件名照合はUnicode正規化フォールバックを追加。

### Task 3: office_styleパス

- `office_marks.jsonl` から、太字・下線・イタリック・色付き文字/塗りを抽出する構造化コンテキストビルダーを追加。
- `build_office_style_context()` を実装。
- RGB16進数を基本色名に寄せる `nearest_basic_color_name()` を追加。
- 暗い赤系の色が `brown` に寄りすぎるケースがあったため、赤成分が明確に優勢な場合は `red` と判定する汎用ヒューリスティックを追加。

### Task 4: spreadsheet_stateパス

- `build_spreadsheet_state_context()` を実装。
- 対応した構造化入力:
  - `train_xlsx_highlight_blocks.jsonl`
    - ハイライトセルの値、列見出し、同じ行の値をコンテキスト化。
  - `spreadsheet_sheets.jsonl`
    - `auto_filter_ref` と非表示行情報からフィルタ状態をコンテキスト化。
  - `schedule_tasks.jsonl`
    - フェーズ名・担当者・ステータス・成果物が質問文に含まれる場合、該当タスク行を列挙。
- 特定案件名・質問番号への分岐は入れていない。

### Task 5: spreadsheet_calcパス

- `SpreadsheetCalcAnswerer` を追加。
- LLMには計算させず、以下のJSON仕様だけを抽出させる設計にした。
  - filters
  - target_column
  - aggregation
  - round_to
- 実計算は `pandas` で決定的に実行。
- 対応集計:
  - `mean`
  - `sum`
  - `count`
  - `max`
  - `min`
- 対応比較:
  - `==`
  - `!=`
  - `>`
  - `<`
  - `>=`
  - `<=`
- `pandas>=2.0` を `pyproject.toml` に追加。
- `.venv` に `pandas` が未インストールだったため、承認付きで `.venv/bin/pip install pandas` を実行。

### Task 6: 列挙・完全性ゲート

- `is_enumeration_complete()` を追加。
- 現時点では `structured_attribute_filter` のみ完全抽出とみなす。
- 候補プール0件、マッチ0件、未知方式は安全側で不完全扱い。

### Task 7: Pipeline統合

- `Pipeline.__init__()` に `artifacts_dir` を追加。
- `scripts/run_pipeline.py` から `Pipeline(..., artifacts_dir=args.artifacts_dir)` を渡すように変更。
- `_process_one()` で質問タグを見て、以下の順に処理するようにした。
  1. 構造化タグがある場合は構造化パスを試す。
  2. 案件名や対象データが解決できない場合は通常検索へフォールバック。
  3. `spreadsheet_calc` は `SpreadsheetCalcAnswerer` を使用。
  4. `office_style` / `spreadsheet_state` は構造化コンテキストを `AnswerGenerator.generate()` に渡す。
- 案件名解決は `ProjectScopedRetriever.detect_project()` を優先し、未検出時は `StructuredArtifactStore.project_names()` をNFC正規化して照合。
