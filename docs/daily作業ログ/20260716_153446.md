# 20260716_153446 Q6不要集計値の除外

## 目的

直近official較正でIncorrectだったQ6について、質問が求めない集計値の付加を汎用的に止める。

## 結果サマリ

- 原因はPivot機械直答テンプレートが内部検証用の最大値を最終回答にも付加していたこと。
- 値の存在確認は完全性ゲートとして維持し、出力だけを「抽出条件＋集計内容」に限定した。
- 外部通信なしの実データQ6 N=3は回答・経路・ゲート状態が完全一致。
- コミット: `6ca3746`。

## やったこと

- `tests/test_pipeline.py`の汎用Pivot fixtureで、要求されない集計値を出力しない失敗テストを追加。
- 修正前: 対象testは`123.0`が回答に含まれてFAILED。
- 修正後: 対象2 tests passed。`.venv/bin/pytest tests/ -v`は**631 passed in 5.63s**。
- 実データQ6: 3回とも`抽出条件: Gender = Male、disease = 1、Age = 68、集計内容: 平均 / ALP`、`structured:spreadsheet_state`、ungated。
- step-review: CONFIRMED/PLAUSIBLEともになし。

## 学び

- 「最大値の特定に値が必要」と「最終回答に値が必要」は別の要件。内部検証情報を無条件に回答へ露出させない。
- full valid N=3は生成・judge APIへ非公開データを送るため、外部通信の明示承認と分離する必要がある。

## 残課題

- 明示承認後にfull valid N=3を実行し、対象外29問の退行0を確認する。
- 必要な場合のみofficial較正を補助証拠として実行し、最終採否を確定する。
