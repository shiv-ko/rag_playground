## 実装（TDD、コミット2件 + step-review各1回）

### `beec2a4` stabilizerコア（src/orchestrator/answer_stabilizer.py）

- 通貨正規化を数字隣接時のみに限定。JPY（¥￥円jpy）は無印へ、$＄ドルは「<数字>ドル」へ寄せ
  **通貨の区別を維持**（旧: 円/ドル/jpyを位置無関係に削除、¥$も記号として削除）
- 代表回答: NFC同士で頻度カウントし採用回答をNFC形に統一（タイはrun番号最小、挙動維持を検証済み）
- 空per_run_answers → ValueError / 空文字列に正規化されるクラスタの過半 → Missing化（no_majority）
- `align_run_answers` 追加: id→回答dictを質問ID列に整列、欠落はMISSING_RESPONSE補完（棄権票）、
  想定外IDはValueError
- **既存テストの空振り発見**: 「カフェ」はNFDで分解されない（濁点・半濁点なし）ため
  NFC/NFDテストが何も検証していなかった → 「パリ」（パ→ハ+結合半濁点）に修正し `nfc != nfd` ガード追加

### `b56791c` make_predictions.py

  dropped_question_ids_per_run記録）。ValueError全破棄と行欠けCSVを両方解消
- write_predictions()共通化 / 監査書き込みをtry/except隔離
