## flip分析メモ

主な変化:

- Q3: `Incorrect -> Missing`
  - 横断集計の誤答をMissing化できており、守りとしては改善。
- Q10: `Missing -> Incorrect`
  - `confidence=0.4` で通過し、根拠外の情報を含む回答が出た。
  - citation実在チェックだけでは、回答本文全体の捏造を防げない。
- Q14: `Acceptable -> Missing`
  - ローカルjudgeの揺れも含むが、スコア上は悪化。
- Q20: `Perfect -> Missing`
  - ベースラインで正答していた問題が、Phase 1後に検索悪化でMissing化。

## 原因分析

Q20について検索結果を比較した。

質問:

> AYMのPLにおいて、探索的分析・仮説整理フェーズに一致するタスクIDをすべて挙げてください。

ベースライン相当の検索では、正解を含む `スケジュール.xlsx` のチャンクが top3 に入っていた。

Phase 1相当では検索クエリが次のように展開された。

```text
AYMのPLにおいて、探索的分析・仮説整理フェーズに一致するタスクIDをすべて挙げてください。 スケジュール イタリック
```

原因:

- `PL -> スケジュール` は妥当。
- しかし `I -> イタリック` が「一致する」の中の `I` に部分一致して誤展開された。
- その結果、不要な用語が検索クエリに混入し、正解チャンクがtop5外へ落ちた。
