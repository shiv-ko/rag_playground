## 学び

- git logの実装済みコミットと`docs/plan/`のdone_リネームは同期していないことがある
  （`2026-07-06-contract-rule-block.md`が好例）。着手前にgit logで裏取りする一手間が必須
- `msoffcrypto-tool`は復号だけでなく暗号化もできるが、暗号化側に小サイズペイロードでの
  既知でない実装バグ（4KB未満でmini-FAT/regular-FAT不整合）がある。テストフィクスチャ生成で
  同ライブラリの暗号化APIを使う場合はペイロードサイズに注意
