## 学び

1. **mean単独で実験を判定してはいけない**。local judgeが正答をMissingに誤判定する率が高く
   （Q5/Q8/Q17/Q27で実測）、30問meanのrun間ゆらぎ0.10〜0.22の相当部分はjudge起因。
   判定は「多数決＋不安定問一覧＋raw_answer読み＋（必要なら）official較正」のセットで行う
2. **安全機構を「偽陰性があるから」と緩めるのは危険**。引用ゲートの偽陰性（正答を殺す）より
   誤答遮断の価値が大きかった。ゲート系の変更はIncorrect素通り数を必ず監視する
3. **回収したQ18に新リスク**: 「3章です。…」の説明付き回答がofficial judgeでIncorrect（正解「3」）。
   ゲート通過はゴールではなく、**短答系は「値のみ」の超短答**が必要（次実験候補）。
   Q17（未連絡→前回未接触の言い換え）も未解決。この2問は現在ゲート通過中の実弾-1リスク
4. step-review運用の続き: 本ブロックはCONFIRMED 1件（_score重複）のみ。プロンプト変更の
   タスクではレビューより実験（N=3）が主な安全網になる
