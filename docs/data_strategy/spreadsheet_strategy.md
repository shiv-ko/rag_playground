# 表・Excel戦略

## 1. 対象データ

各案件に `02.計画/スケジュール*.xlsx` と `03.データ/train.xlsx` がある。多くの案件では `train.csv` も併存するが、設問は `xlsx` 固有の表示状態を問うことが多い。

フォルダ別の役割:

- `02.計画`: WBS、タスク、担当者、開始日/終了日、工数、進捗、色付き行。
- `03.データ`: 生データ、Pivot、フィルター、グラフ、相関係数、係数、ハイライトセル。
- `04.分析/analysis_outputs`: `metrics.json`, `leaderboard.csv`, `run_summary.json`。

## 2. CSV/TSVとXLSXを分ける

`train.csv`/`train.tsv` は計算用の正規データとして扱う。条件抽出、平均、割合、相関、F1などはコードで計算する。

`train.xlsx` は表示状態を持つ資料として扱う。以下はCSVからは復元できない。

- シート名。
- フィルター条件。
- PivotTableの表示結果。
- セル色、行色。
- グラフ。
- 数式。
- 表示上の相関係数や回帰係数。

勝つためには、同じデータでもCSV系とXLSX系を別インデックスにする。

## 3. 抽出するExcel情報

`openpyxl` 等で以下を保持する。

| 項目 | 用途 |
|---|---|
| workbook path | 案件・資料への参照 |
| sheet name | Sheet1/Sheet2/Pivot/WBSなどの指定に対応 |
| cell address | ハイライトセル、交差セル、数式参照 |
| value | 回答・集計の元データ |
| formula | 予測値、差分、係数計算の根拠 |
| number format | 日付/通貨/割合の解釈 |
| fill color | 黄色/青色/オレンジのハイライト |
| font color | 赤字など |
| bold/italic/underline | 書式条件 |
| merged cells | 表見出しの復元 |
| auto filter | 抽出条件の復元 |
| hidden rows/cols | 表示状態の理解 |
| charts | グラフの系列・軸・元データ |

## 4. 計画xlsxの攻略

`スケジュール.xlsx` / `スケジュール_r1.xlsx` / `スケジュール_r2.xlsx` は、計画・進捗・担当者に関する得点源。

構造化テーブルとして抽出する項目:

- タスクID
- タスク名
- フェーズNo
- マイルストーンID
- 担当者
- 役割
- 開始日
- 終了日
- 想定工数
- 実績工数
- 進捗/ステータス
- 行色

色付き行を問う設問があるため、行全体のfillも抽出する。セル単位だけでなく「同じ行のタスク名/タスクID」を引ける形にする。

## 5. train.xlsxの攻略

よくある設問:

- 黄色/青色ハイライトセルの値や条件。
- PivotTableの最大/最小。
- フィルターで抽出されている条件。
- ヒストグラムの最頻ビン。
- 回帰係数を特定行に当てはめる。
- 相関係数シートでハイライトされた条件。
- グラフが可視化しているカラム。

戦略:

1. すべてのシートをセルテーブル化する。
2. 色付きセルを `highlight_cells` として別テーブル化する。
3. 数式セルは参照先を展開できるように保持する。
4. グラフがある場合は、系列名・元データ範囲・軸ラベルを抽出する。
5. 生CSVと同じ行IDがある場合、ExcelセルとCSV行を紐づける。

## 6. 集計問題の解き方

LLMに計算させない。質問から条件を抽出し、pandas相当の処理で計算する。

必要な処理:

- 等値条件: `Gender=Male`
- 範囲条件: `MonthlyIncome > 10000`
- 欠損条件: `1つでも欠損値がある`
- groupby平均/合計/件数
- 相関
- 四捨五入、切り上げ、小数桁指定
- F1スコアなど評価指標
- 回帰係数の適用

数値問題は完全一致が重要なので、計算過程と丸め規則をログに残す。

## 7. 回答ゲート

Excel問題で答える条件:

- 対象workbookとsheetが解決できる。
- 色/フィルター/Pivot/グラフなど質問の対象状態を抽出済み。
- 計算に使った行数と条件がログに残る。
- 丸め・単位変換が質問文どおり。

上記を満たさない場合はMissing。特にセル色問題は推測で答えない。
