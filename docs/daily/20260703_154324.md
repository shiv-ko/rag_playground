# 20260703_154324 データ戦略作業ログ

## 目的

ベースライン実装とは別に、後で高得点化に必要になるデータ理解・構造化・ルーティング基盤を整備した。狙いは、文書チャンク検索だけでは取れない設問を、データ種別ごとの専用抽出と中間成果物で扱えるようにすること。

## やったこと

### 1. データ戦略ドキュメント群を作成

`docs/data_strategy/` 配下に、データ種別ごとの詳細戦略を作成した。

- `README.md`: 全体方針と文書一覧
- `question_taxonomy.md`: 設問分類と得点戦略
- `metadata_and_routing.md`: metadata、案件/略称/資料種別ルーティング
- `office_visual_strategy.md`: docx/pptx/pdf、書式・ページ・強調表現
- `spreadsheet_strategy.md`: xlsx/csv/tsv、Pivot、フィルター、セル色、集計
- `analysis_artifacts_strategy.md`: Notebook、コード、metrics、図表
- `version_diff_strategy.md`: old/v1/v2/v3/finalなどの新旧比較
- `cross_project_rules_strategy.md`: 社内管理、契約、APR、全案件横断集計

意図:

- `dataset_overview.md` は静的な概要に留め、勝つための実装判断は別文書に分離する。
- 「どのデータをどう構造化すれば何問に効くか」を後から追えるようにする。
